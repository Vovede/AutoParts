
# AutoParts — Интернет-магазин автозапчастей

## О проекте

AutoParts — клиентская часть интернет-магазина автомобильных запчастей.

Проект разработан в рамках курсовой работы по дисциплине
«Проектирование и разработка клиентских частей интернет-ресурсов».

Цель проекта — создание удобного и адаптивного веб-интерфейса,
позволяющего пользователям просматривать каталог автозапчастей,
изучать характеристики товаров, формировать корзину и оформлять заказы.

## Функциональные возможности

### Главная страница
- Навигация по основным разделам сайта.
- Поиск товаров.
- Просмотр категорий автозапчастей.
- Отображение популярных товаров.
- Переключение светлой и тёмной темы.

### Каталог товаров
- Просмотр доступных товаров.
- Поиск по названию и бренду.
- Фильтрация по категориям.
- Сортировка по названию и стоимости.
- Переход к подробной информации о товаре.
- Добавление товаров в корзину.

### Карточка товара
- Просмотр названия и характеристик товара.
- Отображение бренда, категории и стоимости.
- Выбор необходимого количества.
- Добавление выбранного количества в корзину.

### Корзина
- Просмотр добавленных товаров.
- Изменение количества товаров.
- Удаление отдельных позиций.
- Очистка корзины.
- Автоматический расчёт общей стоимости.

### Оформление заказа
- Ввод контактных данных покупателя.
- Выбор способа доставки.
- Выбор способа оплаты.
- Расчёт стоимости доставки и заказа.
- Проверка заполнения формы.
- Сохранение оформленного заказа.

### Страница «О магазине»
- Информация о проекте AutoParts.
- Описание преимуществ магазина.
- Переход к каталогу товаров.

## Используемые технологии

- **HTML5** — структура веб-страниц.
- **CSS3** — оформление интерфейса и адаптивная вёрстка.
- **JavaScript** — клиентская логика и интерактивные элементы.
- **LocalStorage** — хранение корзины, настроек темы и заказов.
- **Git** — контроль версий проекта.
- **GitHub** — удалённое хранение исходного кода.
- **Visual Studio Code** — среда разработки.

## Запуск проекта

1. Склонировать репозиторий или скачать исходный код.
2. Открыть папку проекта в Visual Studio Code.
3. Установить расширение Live Server.
4. Открыть файл `index.html`.
5. Нажать правой кнопкой мыши и выбрать `Open with Live Server`.

Проект работает в браузере без необходимости установки дополнительных
пакетов или запуска серверной части.

## Особенности реализации

Проект использует демонстрационные данные товаров, хранящиеся
в JavaScript.

Корзина, настройки темы и оформленные заказы сохраняются
в LocalStorage браузера.

Серверная часть и реальная обработка платежей не реализованы.
Оформление заказа является демонстрационным.

Интерфейс адаптирован для настольных компьютеров, планшетов
и мобильных устройств.
